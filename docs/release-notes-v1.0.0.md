# AI QQ Bot v1.0.0

第一个正式版本。已在 **真实 QQ 账号 + NapCat + DeepSeek** 上完成端到端验证。

## 本次更新的重点：一键启动

装好之后，日常使用只需要**双击一个文件**：

| 文件 | 作用 |
| --- | --- |
| `start_all.bat` | **推荐**：自动以管理员权限启动 NapCat，等端口就绪后再启动机器人 |
| `start_bot.bat` | 只启动机器人（NapCat 已在运行时用） |
| `start_bot.bat --check` | 只做健康检查，不启动 |

脚本会在启动前依次检查：

- 虚拟环境是否存在（不存在会直接告诉你重建命令）
- `.env` 是否存在
- `AI_API_KEY` 是否真的填了（没填就报错，不会傻等）
- NapCat 是否已在运行（已在跑则跳过，不会重复拉起）

## 完整功能

- **四种触发方式**：`@机器人 提问`、`/ai 问题`（兼容 `/ai问题`）、`/帮助`、`/清空`
- **私聊支持**：私聊里不用 @，直接发消息即可提问
- **上下文按「群 + 用户」完全隔离**，私聊单独作为一个会话空间
- 上下文轮数上限（默认 5 轮），用于控制 API 费用
- 用户请求冷却（默认 5 秒，可设为 0 关闭）
- 超长问题拒绝、超长回复自动截断
- DeepSeek 错误分类与中文提示：鉴权失败 / 余额不足 / 模型不存在 / 限流 / 超时 / 网络故障 / 服务端故障
- 对话历史两套后端：内存（默认）或 SQLite 持久化
- 日志密钥自动脱敏
- 无需 QQ 也能自测的链路检查脚本

## 修复的问题

- 修复 `.env` 中 `SUPERUSERS=`（留空）或逗号分隔写法导致**机器人无法启动**的问题
- 修复私聊场景下独立冷却响应器会**阻断后续响应器**的问题
- 修复 401 / 404 被**误分类**为通用错误的问题
- 修复超长问题被**静默截断后仍发送给 AI** 的问题
- 修复 `loguru` 异步写日志在受限环境下报 `WinError 5` 的问题
- 修复探测脚本会把**完整 Token 打印到控制台**的问题

## 安全

- API Key 与 OneBot Token 只存放于 `.env`，用 `SecretStr` 承载，打印配置时自动打码
- `.gitignore` 排除 `.env`、虚拟环境、日志、数据库、NapCat 登录凭据
- 自动化测试会扫描源码与 Git 历史中的疑似密钥
- 默认只监听 `127.0.0.1`

## 安装

```powershell
# 1. 依赖
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 2. 配置
copy .env.example .env
notepad .env      # 填 AI_API_KEY 和 ONEBOT_ACCESS_TOKEN

# 3. 启动（装好之后日常只需双击 start_all.bat）
.\.venv\Scripts\python.exe bot.py
```

详细步骤见 [README](README.md) 与 [docs/setup_windows.md](docs/setup_windows.md)。

## 已知限制

- NapCat 属于**非官方** QQ 接入方案，存在账号风险，**请使用测试小号**
- 私聊对任何能给机器人发消息的人都会触发 AI（群聊必须 @ 或 `/ai`）
- 余额不足（HTTP 402）的真实报错未实测，仅有单元测试覆盖
- `deepseek-reasoner` 模型未用真实 Key 调用过
