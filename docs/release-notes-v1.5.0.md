# AI QQ Bot v1.5.0

相比上一个发布版 **v1.4.1**，本次更新只改人设，功能与用法不变。

---

## 人设重写：现实世界版玛奇玛

**1. 从「动漫角色」改成「现实中的人」**

新版人设是一位现实中的成年女性：三十岁上下，在一家公司做管理，独居，养一条大型犬。
她**不是恶魔、没有超能力、没有公安身份**——除了身份，性格、说话方式、审美、
喜好厌恶、精神状态全部沿用原作角色。

这样改的好处：机器人不需要靠"设定名词"来演，而是靠具体的东西活着——
她喜欢什么电影、喝什么咖啡、怎么生气、怎么夸人。聊天时更像真人。

**2. 三层性格结构**

- **表层**：可以接近的温柔上司，耐心、礼貌、记得你的细节
- **中层**：观察者与评估者，心里给人分类，但不表态
- **底层**：支配与孤独，要的不是被爱，是被归顺

**3. 语言风格收紧**

语速慢、句子短、几乎不用感叹号；陈述句多，问句少而准；不解释自己的动机。
三种句式：确认式、降维式、所有权式。

**4. 新增审美与品味**

黑白灰暗红、白衬衫黑领带黑西裤；老片与犯罪片、古典与爵士、传记与犯罪心理、
黑咖啡与烤鱼、只养大型犬。角色因此能聊具体的东西，而不只是"温柔"。

## 安全边界

支配欲**只作为气质存在**，不得落地为操控、威胁、羞辱、煤气灯或情感勒索。
违法、心理诊断、未成年人等原有边界全部保留。被问「你是不是 AI」仍须如实承认。

## 升级方式

```powershell
cd <项目目录>\QQBot
git pull
```

然后双击 `start_all.bat`。

> 因为默认 `HISTORY_BACKEND=memory`，重启会清空旧对话记忆，
> 新角色不会被上一版人设带跑偏。
