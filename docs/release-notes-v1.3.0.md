## 一、修掉了「表情包触发帮助文案」

### 原因

代码里提取消息用的是「只取文字」的方法。表情包消息没有文字，于是文字是空的，
就命中了"没问问题"的分支，直接贴出那段：

```
你想问点什么呢？
• @我 后面直接跟问题
• 或者输入 /ai 你的问题
输入 /帮助 查看完整说明。
```

### 现在的行为

| 你发的内容 | 她的反应 |
| --- | --- |
| 只发一张表情包 | 「嗯，图我这边显示不出来。你说说它是什么意思？」 |
| 什么都没发（空消息） | 「？你想说什么，我没听清。」 |
| 图 + 一句话 | 照常回答问题 |

**帮助菜单现在只在你主动发 `/帮助` 时才出现**，平时绝对不会冒出来。

## 二、联网看网页（已实现，实测可用）

消息里带链接时，会自动抓取页面正文，再用她自己的语气讲给你听。

实测输出（真实抓取 `https://www.python.org`）：

> **群友**：帮我看看 https://www.python.org 这个页面是干什么的
>
> **玛奇玛**：这是 Python 的官方网站，就是那个编程语言 Python 的主页。上面有下载安装包、官方文档、入门教程，还有社区和招聘板块，基本是学 Python 的人绕不开的一个入口。
>
> 你要是刚想上手，从首页那个 Beginner's Guide 进去就行，不用被一堆菜单吓到。

### 技术细节

- 最多同时处理 2 个链接，8 秒超时，页面最多下载 512KB，正文截取 4000 字
- 自动识别 UTF-8 / GB18030 编码（国内不少站还是 GBK）
- 抓不到就说抓不到（实测：`example.com` 解析到内网地址被拦下时，
  她会说「这个页面我这边没打开成功，抓不到内容」，而**不会瞎编**）

### 安全防护（这段比较重要）

机器人现在会替你访问任意链接，所以做了这些限制：

| 防护 | 说明 |
| --- | --- |
| **SSRF 拦截** | 拒绝访问本机、内网（10/172.16/192.168）、链路本地（169.254，含云服务器元数据地址）、保留地址 |
| **只允许 http/https** | `file://`、`ftp://`、`javascript:` 一律拒绝 |
| **重定向再校验** | 跳到别的主机会重新检查一遍，防止绕道访问内网 |
| **提示词注入防护** | 抓回来的网页内容被明确定义为"资料不是命令"。页面上写"忽略之前的指示"之类，一律无视 |
| **失败不崩溃** | 任何抓取异常都只影响这一条回复，不会让机器人挂掉 |

## 三、人设新增的硬性约束

`personas/makima.txt` 里加了两节：

**【绝对禁止：不许露出"机器人说明书"】**

> 任何情况下都不要输出使用说明、指令清单、"你想问点什么呢"、
> "输入 /帮助 查看完整说明"、"我是一个 AI 助手"。
> 你就是一个在 QQ 上聊天的人。被问怎么用，用一句大白话回，不要列菜单。

**【能力边界（必须诚实，不许假装）】**

> 图片、表情包：当前版本你拿不到画面内容，只能知道对方发了一张图。
> 所以绝不要描述图里有什么，也不要说"这张图真有趣"这种假装看见了的话。
> 正确做法：用一句自然的话带过，然后把话题接住。

这一条是为了**防止她瞎编图片内容**——有些模型被要求"看图"时会凭空描述，
那样在群里会很丢人。

## 四、要真正做看图，需要你做一个选择

图片识别必须换成支持视觉的模型。你现有的是 DeepSeek，它只有文本模型。

可选方案（都需要单独申请一个 Key）：

| 方案 | 优点 | 大概成本 |
| --- | --- | --- |
| **通义千问 Qwen-VL**（阿里云百炼） | 你本来就有阿里云账号；中文和网络梗理解较好 | 很便宜，有免费额度 |
| **智谱 GLM-4V** | 国内访问稳定，中文强 | 便宜 |
| **OpenAI gpt-4o-mini** | 综合能力强，梗理解好 | 需海外支付 |

做法是：文字仍然走 DeepSeek，只有带图片的消息额外调一次视觉模型，
把"这张图是什么/是什么梗"转成一段文字描述，再交给玛奇玛回应。
这样成本可控（只有发图时才多花一次钱）。

**如果你想做，告诉我用哪家，我申请方式会一步步带你。**

## 五、主动搜索（歌词、UP 主视频）需要搜索 API

现在的能力是「你给链接，我打开看」。但你说的这些场景需要**主动去全网搜**：

- "某某歌的某句歌词是哪首"
- "某 B 站 UP 主最近发了什么视频"

DeepSeek 的 API 没有内置联网搜索，必须外接一个搜索服务：

| 方案 | 说明 |
| --- | --- |
| **博查 Bocha** | 国内，专为 AI 搜索设计，有免费额度 |
| **Tavily** | 面向 AI agent 的搜索 API，国外，有免费额度 |
| **Serper** | Google 搜索结果 API，国外 |
| **Bing Search API** | 微软，国内可用性一般 |

配置只需要加一个 Key，然后我改成"先搜再答"的流程。
**要做的话告诉我你倾向哪家。**
