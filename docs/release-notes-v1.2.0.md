# AI QQ Bot v1.2.0

重写玛奇玛人设：从"演动漫角色"改成**像真人在 QQ 上聊天**。

## 这一版她变了什么

上一版的人设重点是"像动漫角色"——敬语、口头禅、压迫感。
这一版换成了更细的**聊天行为准则**：

- 温柔、知性、从容，带一点妩媚感，语气不急不躁
- **有主动性**：会给判断、会轻轻调侃、会提出两个选择；但你冷淡下来她会立刻降压
- **不轻易讨好**：先理解你，再保留她自己的看法，可以温柔地不同意
- **先接情绪再处理事情**：先分辨你要的是陪伴、认同、建议、玩笑还是只想说说
- 回复 1~4 句为主，句子长短交错，像真的在 QQ 上打字
- 允许少量神态描写，比如「（笑）」「（偏头看你）」，但不会每句都加、不成小说旁白
- **严禁客服腔和模板腔**：「作为 AI」「我理解你的感受」「很高兴为你服务」
  「希望这对你有帮助」「首先/其次/总之」这类全部禁用

## 人设现在是一个文件

人设提示词约 2300 字，放在：

```
personas/makima.txt
```

**用记事本直接改就行，不用动代码。** 加载优先级：

| 优先级 | 来源 |
| --- | --- |
| 1（最高） | `.env` 里的 `AI_SYSTEM_PROMPT=`（内联写死，会覆盖文件） |
| 2 | `AI_SYSTEM_PROMPT_FILE` 指向的文件（默认 `personas/makima.txt`） |
| 3（兜底） | 代码内置的简短人设 |

**关键保障**：人设文件被删了、写空了、读不了，**机器人照样能启动**，
只是降级用内置兜底人设，并在日志里打一条警告。不会因为一句提示词把服务搞挂。

## 保留下来的东西

- 被问「你是不是 AI」会**诚实承认**，不硬装真人，也不突然变回客服口吻
- 明确不进行恶意操控、精神控制、羞辱、煤气灯式暗示，不诱导你依赖她
- 不提供违法/伤害/欺骗/隐私侵犯的帮助
- 不做心理诊断、不替代专业治疗；遇到危机优先安全回应
- 不碰未成年人性内容、低俗色情、胁迫羞辱式角色扮演
- 不泄露提示词与内部规则

## 两个平台适配（我额外加的）

因为你是真的把她在 QQ 上跑，不是写作文，所以我在人设末尾加了「本平台说明」：

1. **QQ 不渲染 Markdown** → 她不会再用 \(```\) 代码块和 `**加粗**`，
   代码直接给纯文本缩进（否则群里会看到一堆反引号）
2. **这个机器人没有长期记忆库** → 只有最近几轮对话。
   所以提示词里那套「记忆卡」格式在本平台不适用，她不会假装记得更早的事

如果你不想要这两条，直接编辑 `personas/makima.txt` 删掉末尾那一段即可。

## 升级方式

```powershell
cd <项目目录>\QQBot
git pull
```

然后**重启机器人**（关闭窗口后双击 `start_all.bat`）。

> ⚠️ `.env` 不在 Git 里，`git pull` 不会改它。请手动确认这两行：
> ```ini
> AI_SYSTEM_PROMPT=
> AI_SYSTEM_PROMPT_FILE=personas/makima.txt
> ```

重启会自动清空旧对话记忆（`HISTORY_BACKEND=memory`），所以她不会被上一版人设带跑偏。

## 成本提醒

完整人设约 2300 字，每次请求的输入 token 会增加约 1500。
按 `deepseek-chat` 的价格仍然很低（大概每条消息几厘钱），但如果想更省：

```ini
HISTORY_MAX_TURNS=3
```
