# AI QQ Bot v1.4.1

相比上一个发布版 **v1.0.1**，本次更新带来以下变化。

---

## 新增能力

**1. 图片与表情包识别**

机器人现在能真正"看见"消息里的图片和表情包，随提问一起发给模型理解。
支持 JPEG / PNG / GIF / WebP（按文件头判断），单图上限 8MB、一次最多 3 张；
下载失败时降级为直接传链接；内网地址一律拒绝。

**2. 网页抓取**

消息里带 `http(s)` 链接时，自动抓取页面正文作为参考资料，让机器人用自己的话概括。
最多 2 个链接、8 秒超时、512KB 上限、正文截取 4000 字，支持 UTF-8 / GB18030；
带 SSRF 防护与提示词注入防护，抓不到就如实说，不编造。

## 人设

**3. 默认人设改为《电锯人》玛奇玛**

并重写为"像真人在 QQ 上聊天"的风格：温柔知性、情绪稳定、回复 1~4 句为主，
禁止客服腔与模板腔；被问是不是 AI 会诚实承认；保留违法、心理诊断、未成年人等安全边界。

人设提示词独立到 `personas/makima.txt`，通过 `AI_SYSTEM_PROMPT_FILE` 加载，
文件缺失或为空时自动回落到内置兜底。

## 启动与运行

**4. 一键启动脚本**

新增 `start_all.bat`（同时拉起 NapCat 和机器人）与 `start_bot.bat`（只启动机器人），
自动检查虚拟环境、`.env`、API Key 和端口占用。

**5. 快速登录，不再每次扫码**

启动时带上 QQ 号复用本地已保存的会话，正常情况直接登录。

**6. 修复脚本在真实环境下打不开 NapCat**

三个叠加问题：批处理是 LF 行尾（改为 CRLF）、混入中文注释（改为纯 ASCII）、
没有管理员权限（改为自动提权，用 SID `S-1-16-12288` 检测并带 `--elevated` 防死循环）。

## 修复

**7. 纯表情包不再弹出"AI 使用说明"**

以前只发图片时文字为空，会误触发帮助菜单；现在只回一句人话，帮助菜单仅在 `/帮助` 时出现。

**8. 人设回复更简短**

去掉神态动作描写，要求言简意赅、不复述用户的话、不用口头禅。

## 升级方式

```powershell
cd <项目目录>\QQBot
git pull
```

然后双击 `start_all.bat`。
