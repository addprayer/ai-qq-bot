# AI QQ Bot v1.5.1

相比上一个发布版 **v1.5.0**，本次更新只改回复格式，功能与用法不变。

---

## 一句话回复，不再换行

**问题**：机器人以前偶尔会把一句话拆成好几行，在 QQ 群里看起来很割裂，
像在发小作文，不像随手打的一句话。

**现在的效果**：不管模型怎么输出，发到群里的一定是一行连续的文字。

示例（真实调用）：

> （抬眼看过来，停了一下）你好。这么客气，是第一次跟我说话，还是有事想让我帮忙。

> （放下杯子，看你一眼）我不列清单。少吃，多走，早点睡——三件事，做得到再说。

**怎么做到的**：

1. **人设层**：`personas/makima.txt` 的输出要求改成「只说一句话，不换行、不分段、不列点」，
   每轮自检里也加了「是否换行分段」这一项。
2. **代码层兜底**：`src/message_handler.py` 新增 `to_single_line()`，
   在 `truncate_reply()` 里对所有回复统一处理——中文换行直接删掉，
   英文/数字相邻时才补一个空格，避免把两个单词粘在一起。

两层配合：模型听话时本来就单行；模型不听话时，代码也会把它压成一行。

## 修复

- **Git 历史扫描测试在 Windows 下会误报失败**：`subprocess` 默认按 GBK 解码 git 的 UTF-8
  输出，遇到中文提交信息会解码失败并返回 `None`。已改为显式 `encoding="utf-8"`。
